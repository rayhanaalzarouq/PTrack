# Personas

## PER-PM-001: Solo Software Engineer
| Field | Value |
|-------|--------|
| Persona ID | PER-PM-001 |
| Role | Software engineer who manages one or more personal software projects |
| Access Level | Single local user; no login or account (ADR-004) |
| Environment | Modern desktop browser (NFR-004) |
| Related Screens | UI-PM-001 to UI-PM-009, UI-STG-001, UI-DATA-001, UI-GEN-001 |
### Goals
- See all projects and where each one stands, at a glance.
- Keep each project's development stage current with minimal effort.
- Find a project quickly by name.
### Context and Pain Points
- Works on several projects at once and, without a clear way to track progress, loses focus and leaves projects unfinished.
- Wants a simple tracker, not a full project management suite.
- Is familiar with the basic development stages and updates the stage manually.
