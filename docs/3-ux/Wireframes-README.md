Wireframes
==========

Purpose
-------
Mockup images or links (e.g., Figma URLs), named by UI ID, one per screen.
This folder holds the visual source of truth referenced from each screen's
"Mockup Link" field (see modules/Project Management/UI-PM-001.md, Section 7).

Convention
----------
- File name matches the UI ID it documents (e.g., `UI-PM-001.png`, or a
  `UI-PM-001.md` containing a Figma link if no static export is kept here).
