# Accessibility
---
## Target
- WCAG 2.1 Level A.
- Applies to: UI-PM-001 to UI-PM-009, UI-STG-001, UI-DATA-001, UI-GEN-001.
---
## Criteria
| # | Area | Criterion | WCAG 2.1 (Level A) | Applies to |
|---|------|-----------|---------------------|------------|
| A1 | Keyboard | Every action (search, create, select project, open stage dropdown, choose stage, open the three-dot menu, edit, delete, try again, close the details) can be done with the keyboard alone | 2.1.1 Keyboard | All screens |
| A2 | Keyboard | The three-dot menu and stage dropdown can be left with the keyboard; focus is never trapped | 2.1.2 No Keyboard Trap | UI-PM-008, UI-STG-001 |
| A3 | Focus | Focus order follows the visual order; when the three-dot menu or the stage dropdown opens, focus moves into it, and when it closes, focus returns to the control that opened it | 2.4.3 Focus Order | UI-PM-003, UI-PM-008, UI-STG-001 |
| A4 | Labels | Search bar, name field, description field, and the status and stage control each have a visible, programmatically associated label | 1.3.1 Info and Relationships; 3.3.2 Labels or Instructions | UI-PM-002, UI-PM-004, UI-PM-005, UI-STG-001 |
| A5 | Errors | Name required, name already used, save failure, and generic errors are identified in text and, for form errors, tied to the affected field | 3.3.1 Error Identification | UI-PM-006, UI-PM-007, UI-DATA-001, UI-GEN-001 |
| A6 | Color | Empty, warning, error, and no-results states are not conveyed by color alone | 1.4.1 Use of Color | UI-PM-001, UI-PM-005, UI-PM-006, UI-PM-007, UI-DATA-001, UI-GEN-001 |
| A7 | Name, role, value | The details card, dropdown, three-dot menu, and buttons expose their name, role, and state to assistive technology | 4.1.2 Name, Role, Value | UI-PM-003, UI-PM-008, UI-STG-001 |
| A8 | Page | The page has a descriptive title | 2.4.2 Page Titled | All screens |
| A9 | Instructions | The description counter shows the characters used and the maximum (250) as text, so the user knows why typing stops | 3.3.2 Labels or Instructions | UI-PM-004 |
---
## Notes
- Criteria are written against documented behavior in FR-PM-001 to FR-PM-004, FR-STG/STS, and FR-DATA-001; they are to be verified in the Testing phase.
